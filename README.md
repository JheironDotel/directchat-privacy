## Purpose

This repository provides a public, version-controlled Privacy Policy for Direct Chat No Save.

The Privacy Policy describes the application's data handling practices, local storage, third-party services, Google AdMob advertising, Google User Messaging Platform (UMP), and applicable user privacy choices.

## Publishing

The Privacy Policy is published using GitHub Pages from the root directory of the main branch.

Configuration:

- Source: Deploy from a branch.
- Branch: main.
- Directory: / (root).
- HTTPS enabled.

No external privacy policy generator or custom backend is required.

## Maintenance

When updating the Privacy Policy:

1. Review changes to application functionality and data processing practices.
2. Update both language versions.
3. Update the last modified date.
4. Commit and push the changes to the main branch.
5. Verify that both public pages display the updated content.
